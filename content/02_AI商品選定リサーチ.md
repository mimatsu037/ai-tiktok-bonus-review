# 特典02｜売れる可能性を見極める AI商品選定リサーチツール

## 商品選定の8項目

各項目を5点満点で採点します。合計40点中30点以上を優先候補にします。

| 評価項目 | 確認すること |
|---|---|
| 悩みの強さ | 視聴者が今すぐ解決したい問題か |
| 見た目の変化 | 使用前後や使用シーンを動画で見せられるか |
| 説明の簡単さ | 15～45秒で価値が伝わるか |
| 信頼性 | 自分の体験や一次情報で説明できるか |
| 切り口の多さ | 1商品から10本以上の動画を作れるか |
| 購入ハードル | 価格、配送、使い方が大きな障壁にならないか |
| 報酬条件 | 成果条件と否認条件を理解できているか |
| ルール適合 | 紹介表現や素材利用に問題がないか |

## コピペ用プロンプト

```text
あなたはショート動画の商品企画担当者です。
以下の商品をTikTokで紹介する候補として分析してください。

商品名：【商品名】
商品ページに記載された特徴：【事実のみ記載】
価格：【価格】
想定視聴者：【人物像】
私が実際に使った感想：【感想】
成果条件・禁止事項：【ASP等で確認した内容】

次の8項目を各5点で採点してください。
悩みの強さ／見た目の変化／説明の簡単さ／信頼性／切り口の多さ／購入ハードル／報酬条件／ルール適合

そのうえで以下を出力してください。
1. 合計点と優先度（今すぐ試す／保留／見送る）
2. この商品が刺さる人
3. 誇張せず訴求できるベネフィット3つ
4. 動画の切り口10個
5. 購入を迷う理由5つと、それに答える方法
6. 投稿前に事実確認すべき表現
7. 3本で検証するテスト計画

不明な情報を推測で補わず、「要確認」と明記してください。
```

## 3本テストの基本

- 1本目：悩み訴求。「こんなことで困っていませんか？」
- 2本目：実演訴求。使い方や変化を画面で見せる
- 3本目：比較訴求。向いている人・向いていない人を整理する

3本とも商品は変えず、冒頭と切り口だけを変えて反応を比較します。
