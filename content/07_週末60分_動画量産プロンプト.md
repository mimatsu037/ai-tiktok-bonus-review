# 特典07｜週末60分プランナー

毎日投稿を目標にする前に、今の生活で続けられる3本を計画します。量よりも、「何を試した投稿か」が分かる一週間にします。

## 今週のテーマを1つ選ぶ

- 紹介する商品・サービス：
- 届けたい相手：
- 今週確かめたいこと：

例：実演から始めると、最後まで見てもらいやすいか。

## 3本の役割を分ける

| 投稿 | 役割 | 内容メモ |
|---|---|---|
| 1本目 | 共感 | 困っている場面を見せる |
| 2本目 | 実演 | 使っているところを見せる |
| 3本目 | 判断材料 | 向いている人・注意点を伝える |

同じ商品で役割だけを変えると、何が反応につながったのか比べやすくなります。

## AIに3本の切り口を広げてもらう

商品・相手・確かめたいことを自分で決めた後に使います。AIには7本分を一括生成させず、比較できる3本へ絞ってもらいます。

```prompt
あなたは、TikTok投稿を無理なく続けるための企画アシスタントです。

下の情報をもとに、同じ商品・同じ視聴者のまま、役割の違う3本を提案してください。

- 1本目：共感
- 2本目：実演
- 3本目：判断材料

各投稿について、次の4項目だけを書いてください。
1. 企画のねらい
2. 冒頭で見せる映像
3. 必要な撮影カット3つ
4. 投稿後に確認する数字

未確認の効果や体験は作らず、撮影に必要な情報が足りなければ先に質問してください。

【商品・届けたい相手・今週確かめたいこと】
（ここに今週のテーマを貼る）
```

## 週末60分の使い方

| 時間 | やること |
|---|---|
| 0～10分 | 今週のテーマと3本の役割を決める |
| 10～25分 | 必要なカットをメモする |
| 25～45分 | 共通して使う素材だけ撮る |
| 45～55分 | 1本目の冒頭を仮編集する |
| 55～60分 | 不足素材と次に相談したい点を書く |

## やらないことも決める

- 7本すべてを一度に完成させない
- 商品やターゲットを投稿ごとに変えない
- 編集テンプレートを作り込みすぎない
- AIの文章を確認せず、そのまま投稿しない

> 今日のゴールは大量投稿を完成させることではなく、検証できる3本の予定を作ることです。

## この先で必要になること

実際の投稿ペースは、撮影時間や編集経験によって変わります。無理な計画になっていないかを確認し、結果を見ながら翌週の本数と役割を調整します。
