# 特典09｜数字の見方・早見表

投稿の数字は、[br]自分を評価する点数ではありません。[br]次の投稿で試すことを考えるヒントです。[br]まずは[br]「事実」「仮説」「次のテスト」を分けます。

![再生から反応・プロフィール・クリックへ進み、改善を繰り返す流れ](assets/illustrations/metrics-improvement-flow.png "数字はゴールではなく、次の小さなテストへ[br]つなげるための材料として見ます。")

## まず記録する4つ

| 見るもの | 記録すること |
|---|---|
| 投稿条件 | 投稿日時、テーマ、動画尺 |
| 視聴 | 再生数、平均視聴時間、完視聴率 |
| 反応 | いいね、コメント、保存、シェア |
| 次の行動 | プロフィール閲覧、リンククリック、成果 |

数字が表示されない、[br]または母数が少ない場合は、[br]無理に結論を出しません。

## 症状別の「最初の見方」

| 気になる状態 | まず観察すること | 次に試す小さな変更 |
|---|---|---|
| 冒頭で離脱していそう | 最初の画面だけでテーマが分かるか | 最初に実物を見せる |
| 見られるが保存が少ない | 後で見返す情報になっているか | 3項目のチェック形式にする |
| プロフィールへ進まない | 投稿とプロフィールのテーマが同じか | CTAを1つだけにする |
| クリック後につながらない | 投稿で期待させた内容とリンク先が同じか | 向いている人を明確にする |

## 事実・仮説・テスト

```text
【事実】数字からそのまま言えること：

【仮説】そうなったかもしれない理由：

【次のテスト】1つだけ変えること：

【変えないこと】比較のために残す条件：

【まだ分からないこと】：
```

## AI診断は「次のテスト」を決めるために使う

AIに原因を断定させるのではなく、[br]複数の可能性を整理し、[br]次の1本で変える要素を1つ選びます。

```prompt
あなたは、TikTok投稿の改善を支援するデータ整理アシスタントです。

下の投稿データと私のメモを読み、数字だけで原因を断定しないでください。
次の形式で回答してください。

1. データから事実として言えること
2. 考えられる仮説を最大3つ
3. 各仮説を確かめるために必要な追加情報
4. 次の1本で変更する要素を1つ
5. 比較のために変更しない要素
6. 人に添削してもらいたいポイント

サンプル数が少ない場合は、その旨を最初に明記してください。

【投稿データとメモ】
（ここに記録内容を貼る）
```

> 今日のゴールは、[br]原因を断定することではなく、[br]次の1本で試す仮説を1つ作ることです。

## この先で必要になること

数字はジャンル・投稿本数・動画尺でも[br]見え方が変わります。[br]単独の数値だけで判断せず、[br]複数の投稿を見比べます。[br]そのうえでフィードバックを受けると、[br]思い込みを減らせます。
