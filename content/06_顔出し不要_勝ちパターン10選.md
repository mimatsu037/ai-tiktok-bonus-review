# 特典06｜顔出しなし撮影レシピ

顔を出さなくても、商品のサイズ・動き・使う場面が見えれば内容は伝わります。下の具体例から、手持ちのスマホで再現できる撮り方をひとつ選びます。

![スマホ・三脚・ライトを使った顔出しなしの手元撮影セット](assets/illustrations/faceless-filming-setup.png "スマホを固定し、手元・商品・光の向きを先に整えると、顔を出さなくても見やすい映像になります。")

## 5つの撮影レシピと完成イメージ

| 撮り方 | 3カットの流れ | 具体例 |
|---|---|---|
| **手元で実演** | 困りごと → 使う瞬間 → 使用後 | 洗面台の水滴 → クロスで拭く手元 → 乾いた面と注意点 |
| **大きさを比較** | 商品全体 → 手と並べる → 収納 | バッグ正面 → 手に持ったサイズ → 棚へ収める様子 |
| **画面を実演** | 困った画面 → 1操作 → 完了 | 入力前の画面 → ボタンを押す指 → 完了表示 |
| **A・Bを比較** | 比較条件 → 同じ画角 → 向く人 | 2商品を並べる → 同量を試す → 違いを1つ表示 |
| **写真＋声** | 結果写真 → 使用場面 → 注意点 | 完成した収納 → 作業中の写真 → サイズ注意をテロップ表示 |

### 迷ったら「手元で実演」

スマホを固定し、机や洗面台を斜め上から映します。最初の3秒で困っている状態、次に使う手元、最後に変化と注意点を見せると、顔を出さずに内容が伝わります。

## 15秒テストの確認

- 明るさは十分か
- 商品が背景に埋もれていないか
- 手で大事な部分を隠していないか
- 個人情報や第三者の顔が映っていないか
- 商用利用できる音源・素材か

> 今日のゴールは撮影パターンを全部覚えることではなく、自宅で再現できる撮り方をひとつ見つけることです。

## この先で必要になること

同じ撮り方でも、商品の魅力が伝わる角度や順番は変わります。撮った素材を見返し、どこが分かりにくいかフィードバックを受けると改善が早くなります。
