# 特典05｜伝わる台本キャンバス

30秒の台本をいきなり完成させず、[br]伝えたいことを4つの枠へ分けます。[br]空欄がある部分は、[br]調査や体験が必要な場所です。

![4つの枠を順番に並べた台本キャンバス](assets/illustrations/script-canvas.png "台本は、[br]きっかけ・発見・実演・判断材料の順に整理します。[br]空欄は無理に埋めず、[br]確認が必要な場所として残します。")

## 4つの枠

| 枠 | 書くこと | 確認ポイント |
|---|---|---|
| きっかけ | 視聴者が困る具体的な場面 | 誰の話か分かる？ |
| 発見 | 自分が知ったこと・試したこと | 事実と感想を分けた？ |
| 実演 | 画面で見せられる動き | 言葉だけになっていない？ |
| 判断材料 | 向いている人・注意点 | 良い面だけになっていない？ |

## 書き込み用キャンバス

```text
【きっかけ】
こんな場面で困っていた：

【発見】
私が試して分かったこと：

【実演】
画面で見せる3カット：
1.
2.
3.

【判断材料】
向いていそうな人：
先に伝えたい注意点：

【まだ確認できていないこと】

```

## AIには「完成」ではなく「添削」を頼む

キャンバスを自分で埋めた後に使います。元の体験や事実を残したまま、[br]伝わりにくい部分だけ指摘してもらいます。

```prompt
あなたは、誠実なTikTok商品紹介台本の編集者です。

下の台本キャンバスを読み、完成台本を最初から書き直さず、まず添削してください。

1. 視聴者や場面が曖昧な箇所
2. 事実と個人の感想が混ざっている箇所
3. 映像で見せた方が伝わる箇所
4. 誇張・断定に見える可能性がある表現
5. 私に追加で確認したい質問を3つ

その後、私の回答を反映した「冒頭3秒」と「15秒の構成案」を1案だけ出してください。
未確認情報を追加しないでください。

【台本キャンバス】
（ここに記入内容を貼る）
```

## 声に出して確認する

- 一文が長くなりすぎていないか
- 商品説明より、自分の体験が見えるか
- 映像がなくても同じことを言っていないか
- 視聴者へ約束しすぎていないか

> 今日のゴールは、[br]AIに完成台本を書かせることではなく、[br]添削や相談ができる「たたき台」を作ることです。

## この先で必要になること

台本は、[br]話し方・撮影素材・商品のルールに[br]合わせて整えます。[br]完成前に第三者が読むと、[br]伝わりにくい箇所や、[br]言いすぎた表現にも気づけます。
