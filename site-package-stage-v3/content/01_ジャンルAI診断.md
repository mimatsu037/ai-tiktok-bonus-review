# 特典01｜3分でわかる TikTokアフィリジャンルAI診断

## この特典でできること

自分の経験、興味、撮影条件、使える時間から、継続しやすく商品紹介につなげやすい発信ジャンル候補を3つに絞ります。

## コピペ用プロンプト

```text
あなたはTikTokのコンテンツ戦略とアフィリエイト導線設計に詳しいコンサルタントです。
以下の回答をもとに、私が無理なく90日継続できる発信ジャンルを診断してください。

【私の情報】
興味があるテーマ：
実体験があるテーマ：
よく買う商品：
人から相談されること：
顔出し条件：
声出し条件：
1日に使える時間：
初期費用：
撮影できるもの：
避けたいテーマ：
目標報酬：

【評価基準】
1. 継続しやすさ
2. 視聴者の悩みの強さ
3. 商品を自然に紹介できるか
4. 1テーマから動画を量産できるか
5. 顔出し・撮影条件との相性
6. 誇大表現に頼らず価値を伝えられるか

【出力形式】
- おすすめジャンル上位3つ
- 各ジャンルを100点満点で採点
- 想定視聴者を1人の人物像として記載
- 解決する悩みを5つ
- 紹介しやすい商品カテゴリーを5つ
- 最初の動画ネタを10本
- そのジャンルを避けるべき条件
- 最終的に1つ選ぶならどれかと、その理由

初心者が今日から動ける具体性で回答してください。
```

## 最終決定チェック

候補ジャンルについて、次の5項目中4つ以上が「はい」なら有力です。

- そのテーマの動画タイトルを今すぐ30個考えられる
- 実物または使用画面を見せられる
- 視聴者の悩みを具体的な言葉で説明できる
- 週3本以上、3か月続けられる
- 紹介したい商品を自分でも使いたいと思える
